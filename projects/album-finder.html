Album Finder

A simple web application for discovering albums from your favorite artists.

Completed
View on GitHub

Project Overview

Album Finder is a JavaScript-based web application that allows users to search for an artist and discover their albums.

The application uses the iTunes Search API to retrieve album information and dynamically display the results, including album covers, artist names and release dates.

Technologies Used

HTML CSS JavaScript iTunes Search API

Key Features

Artist Search

Search for albums by entering the name of an artist.

Album Discovery

View albums returned from the iTunes Search API.

Album Covers

Display album artwork alongside the search results.

Release Dates

Display the release year of each album.

Album Links

Open album pages through the provided album links.

Dynamic Results

Search results are generated dynamically using JavaScript.

Focus Dungeon

A gamified productivity app designed to make staying focused more engaging.

In Development
View on GitHub

Project Overview

Focus Dungeon is a productivity application that combines focus sessions with game-inspired elements. Instead of treating productivity as another boring timer, the app turns focus sessions into dungeon challenges.

Users can choose different dungeon difficulties, complete timed focus sessions and progress through the application using XP, coins and levels.

Technologies Used

Flutter Dart

Key Features

Focus Timer

Complete timed focus sessions inside a dungeon.

Difficulty Levels

Choose between Easy, Medium and Hard dungeons.

XP & Levels

Earn experience and progress through different levels.

Coin System

Earn coins as part of the gamified productivity system.

Session Controls

Pause, resume or stop an active focus session.

Custom Dungeons

Create custom focus sessions based on your preferences.
